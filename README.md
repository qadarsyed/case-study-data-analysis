# Case Study: Student Retention Analytics (RMIT COSC2669/COSC2816 - Individual Task 1)

Analysis code for a Data Analyst case study (Chisholm Institute role), comparing
two machine learning algorithms (Decision Tree, SVM) across two public datasets:

- OULAD (Open University Learning Analytics Dataset)
- UCI Student Performance Dataset

## Structure
- `code/analyze_student_performance.py` - UCI Student Performance analysis
- `code/analyze_oulad.py` - OULAD analysis
- `outputs/figures/` - confusion matrices, ROC curves, feature importance charts
- `outputs/results/` - metrics tables, classification reports

## Data sources
- OULAD: https://archive.ics.uci.edu/dataset/349/open+university+learning+analytics+dataset (CC BY 4.0)
- UCI Student Performance: https://archive.ics.uci.edu/dataset/320/student+performance (CC BY 4.0)
